Lunar Groove Ceramics

About

This project is a minimal frontend-only website. All assets are served from Cloudflare Workers at the edge — fast, global, and simple to maintain.

Features

  • Static & simple

    Plain HTML, CSS, and JavaScript — no build step required.

  • Edge deployed

    Runs on Cloudflare Workers for low latency worldwide.

  • GitHub ready

    Push to GitHub and deploy automatically with GitHub Actions.

Built with LunarGroove · Deployed on Cloudflare Workers
